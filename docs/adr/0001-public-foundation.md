# 0001: Public project foundation

Date: 2026-11-04. Status: accepted for repository setup.

## Context

The owner wants NexusKratos to be open source and usable by other open-source communities. The platform does not yet exist as runnable software. A separate website repository was explicitly requested.

## Decision

Create public platform and website repositories under NexusKratos, with Apache-2.0 licensing for the newly authored material. Record planned behavior honestly and keep Warboard independently usable, under active development, with integration planned.

## Alternatives rejected

A private or all-rights-reserved foundation would not express the requested open-source direction. Combining website and platform source would ignore the requested repository separation. Moving Warboard's private history is outside this setup and would require its own publication work.

## Consequences

Public contributions can start from documented requirements. No source checkpoint claims an implemented runtime. License text is retained verbatim; third-party additions will need their own provenance. Existing Warboard code and licensing are unchanged.
