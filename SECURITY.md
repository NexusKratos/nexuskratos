# Security policy

## Supported versions

There is no released NexusKratos runtime yet. The current repository contains documentation and design direction. Report problems in this repository or its published project materials; do not test systems you do not own or have permission to assess.

## Private reporting

Email **security@nexuskratos.dev** with the affected repository, version or commit, impact, and a minimal explanation. Do not post secrets or vulnerability details in public issues. No response-time SLA or bug bounty is currently offered.

Provider credentials must never be included in a report. For third-party products, report directly to their maintainers.

## GitHub reporting and repository controls

Private reports can also be submitted through [GitHub private vulnerability reporting](https://github.com/NexusKratos/nexuskratos/security/advisories/new). The [repository security baseline](docs/adr/0002-repository-security.md) records branch/tag protections, Actions policy, scanning settings, and the explicit administrator PR exception.
